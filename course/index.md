# Tutorial Course

Learn RuleBox by building one small thing: a **loan decision**. A customer
applies with a credit score and an amount. Your rules decide
`DECLINED`, `APPROVED`, or `MANUAL_REVIEW`.

Each lesson takes about five minutes and ends with a **Try it** step. By
the end you will have:

- written rules in BoxLang with the `given / when / then` DSL
- read back results and see exactly which rules ran
- moved the rules into a JSON file the business can edit
- used them from a ColdBox handler
- watched them run in the Rule Visualizer

## Before you start

- You can read and write BoxLang, and you have a ColdBox 8 app.
- You do not need to know anything about rules engines.
